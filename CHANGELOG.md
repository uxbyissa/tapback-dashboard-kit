# Changelog

All notable changes to this kit are listed here. Versions follow `MAJOR.MINOR.PATCH`:
- **MAJOR**: a change that breaks existing code (renamed or removed tokens / files)
- **MINOR**: new assets, tokens or components
- **PATCH**: fixes to existing values

## [1.0.0] — 2026-11-08

### Added
- TapBack logo and mark: SVG in lime, navy, white and black; PNG exports; app icons (32, 180, 512)
- 30 SVG icons (Material Symbols, `currentColor`) with a usage map (`assets/icons/ICONS.md`)
- Inter webfont (400, 500, 600, 700) with `@font-face` (`tokens/fonts.css`)
- Design tokens: `tokens.css`, `tokens.json`, `_trezo-overrides.scss`
- Previews: main dashboard, Variant B (lime accent), Concept detail, 10 hover cards, 6 floating elements, interaction flow video
- TapBack Design System (`design-system/`): 16 UX rules, colour / type / spacing / radius / touch tokens (CSS + JSON), 49 line icons, Poppins + IBM Plex Sans Arabic, component reference, 7 board images
- Handoff notes: identity rule, colour rule, Trezo build map, interactions, estimated-value formulas
