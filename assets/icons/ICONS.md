# Icons

All icons are **Material Symbols** (Google, Apache 2.0), weight **300 (Light)**, fill 0, unless the file name ends in `-fill` (fill 1).
Every SVG uses `fill="currentColor"`, so the icon takes the colour of its parent text: set `color` in CSS.

You can use these SVG files directly, or load the Material Symbols font and use the names below.

## Using the font instead

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@20..48,300,0..1,0" />
<span class="material-symbols-outlined">space_dashboard</span>
```
